L6 · Composition Plan

This composition plan documents the layout, positioning, layering, and shape enhancements planned for Postmarked: The Lost Art of Sending Postcards. The design combines vintage postcard details with a modern editorial magazine layout.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
Feature postcard image Introduces the story with decorative postcard artwork. Image appears as a regular figure with a caption Border-radius softens corners and clip-path creates an angled shape. The feature figure provides the visual boundary. Display the original rectangular image if clipping is unsupported. Disable clip-path and test image readability.
Postcard illustration Adds a visual element beside the article text. Image appears as a block before the paragraph. Float and shape-outside create an editorial text wrap. The article section contains the float using flow-root. Use a block image when shape wrapping is unavailable. Disable shape-outside and test at all viewport sizes.
